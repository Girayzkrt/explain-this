# Security policy

## Reporting a vulnerability

Please report security issues **privately**, not in a public issue.

Use GitHub's [private vulnerability reporting](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository. If that is not enabled, use the private maintainer contact published
in the repository's About section or profile.

When reporting, please include the extension version, your Chrome version, your operating
system, and the steps to reproduce. **Do not include page text you were reading**, model
output, or anything else private — a description of the mechanism is enough.

## Scope

This extension runs entirely on your machine and talks only to a local Ollama server on
loopback. Reports are most useful when they concern:

- reading page content the user did not select, or sending it anywhere;
- escaping the reader's Shadow DOM sandbox, or executing model output as code;
- obtaining host permissions beyond the approved loopback origins without user consent;
- writing page text or model output to persistent storage;
- reaching a non-loopback endpoint.

## Known and accepted limitations

These are documented rather than treated as vulnerabilities, because they are properties
of running a small local model rather than defects in the extension:

- **Prompt injection is not prevented.** A hostile page can contain text that steers the
  local model, and small local models comply readily. Evaluation across four models found
  no model that resisted every case, and adding a trust-boundary reminder after the
  untrusted text did not help. What _is_ enforced: model output is rendered as sanitised
  Markdown and cannot execute, create links, or inject DOM; the extension has no network
  egress beyond loopback; and page text never leaves your device. A successful injection
  changes the wording shown in the reader card and nothing else.
- **Model output can be wrong.** Explanations are generated by a small local model and are
  not verified.
